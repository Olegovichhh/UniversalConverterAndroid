# Universal Converter Android

Локальный Android-конвертер файлов по принципу FreeConvert.

## v0.1
- выбор локального файла через Android Storage Access Framework;
- JPG / PNG / WEBP конвертируются на устройстве;
- интерфейс подготовлен для MP3, WAV, FLAC, M4A, MP4 и WEBM;
- пользовательские файлы не загружаются на сервер;
- GitHub Actions автоматически собирает debug APK.

## Скачать APK
Откройте **Actions → Build Android APK → последний успешный запуск → Artifacts → UniversalConverter-0.1-debug**.
